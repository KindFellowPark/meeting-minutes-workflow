# Known Names

> Part of the [minutes-builder](../SKILL.md) skill, read in Step 2.

Read by the minutes-builder skill in Step 2, before any minutes are drafted. Speech-to-text
gets uncommon names wrong more often than anything else, so every name in a transcript is
checked against this list. A near-miss is flagged for the person preparing the minutes to
confirm. Nothing is corrected silently.

This copy holds the fictional names used in the sample meeting. In real use it lists the
people, vendors and programs the office deals with, and it grows each time a new name is
confirmed.
